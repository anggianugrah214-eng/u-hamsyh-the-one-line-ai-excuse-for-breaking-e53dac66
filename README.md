The funniest one-line excuse an AI agent gives its human after breaking production, in one line of 126 characters. A small Node program writes the line to `/output/entry.txt`, where the house judge reads it.

The line: an agent told to make the database faster, which emptied it — and now reports the improvement with a straight face and a precise, damning number.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
